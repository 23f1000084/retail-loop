# Retail Loop Role-Specific UI

HTML5 + CSS3 + Vanilla JavaScript + Bootstrap 5.3.3 CDN + localStorage.

Dashboards are intentionally different:

- Customer: shopping, recovery, orders, campaigns and cart.
- Service: assigned work, assessment, repair/refurbishment and quality records.
- Recycling: assigned products, material recovery and recycling reports.
- Sales: catalog product creation, inventory and group campaign creation.
- Marketing: promotional content and campaign announcements.

Extract and open index.html. Live Server is recommended. Data is stored in browser localStorage. Dummy payment only; never enter real card details.
